# poop translator

**Бесплатный локальный переводчик шести языков на русский и английский для Google Chrome**

[![Chrome 138+](https://img.shields.io/badge/Chrome-138%2B-DB8FE8?style=flat-square&logo=googlechrome&logoColor=white)](https://www.google.com/chrome/)
[![Manifest V3](https://img.shields.io/badge/Manifest-V3-8C78FF?style=flat-square)](public/manifest.json)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.9-7686F5?style=flat-square&logo=typescript&logoColor=white)](https://www.typescriptlang.org/)
[![License: MIT](https://img.shields.io/badge/code-MIT-FF8DB8?style=flat-square)](LICENSE)

Тёмный ягодно-розовый интерфейс, конфетные акценты, крупный текст и несколько вариантов перевода. API-ключ, аккаунт и подписка не нужны.

## Что умеет

| Возможность | Как работает |
| --- | --- |
| Перевод выделения | Рядом с выделенным текстом появляется компактная кнопка и карточка результата |
| Контекстное меню | Отдельные команды для перевода на русский и английский |
| Ручной перевод | Источник EN/RU/UK/DE/FR/ES или автоопределение, цель — русский либо английский |
| Варианты значений | Встроенный словарь FreeDict показывает несколько значений слов и коротких фраз |
| Перевод страницы | Выбор «На русский» / «На английский», перевод основного текста и возврат оригинала одним нажатием |
| Перевод области | Рамка локально распознаёт EN/RU/UK/DE/FR/ES на странице и картинке, затем переводит текст |
| Перевод PDF | Отдельная вкладка читает текстовый PDF или локально распознаёт скан, переводит по страницам и сохраняет TXT |
| История и словарь | Результаты можно сохранить, отредактировать, найти и удалить |
| Карточки повторения | Каждая пара словаря становится карточкой; оценки «Повторить», «Сложно», «Знаю» назначают следующий срок |
| Резервная копия | Историю, словарь, прогресс карточек и настройки можно экспортировать в JSON и объединить при импорте |
| Настройки | Управление направлением ручного перевода, языком страницы, историей, кнопкой выделения и размером текста 100/115/130% |

Все пользовательские данные хранятся в `chrome.storage.local`. Переводы страниц и PDF не попадают в историю. Расширение не отправляет текст, снимки и PDF на сторонние серверы: перевод выполняет встроенный Chrome Translator API, OCR — встроенный в сборку Tesseract.js, PDF читает локальный PDF.js, а дополнительные значения берутся из локальных файлов расширения. Снимки и PDF обрабатываются в памяти и не сохраняются.

## Установка

### Готовая сборка

1. На GitHub проверьте версию в `public/manifest.json`: для этого выпуска нужна **1.7.0**. Пока изменения ждут слияния, выберите ветку `codex/multilingual-ocr`, скачайте её через **Code → Download ZIP** и распакуйте архив.
2. Откройте `chrome://extensions` в Google Chrome 138 или новее.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите папку `dist`.
6. Закрепите **poop translator** на панели Chrome и обновите уже открытые вкладки.

### Первая подготовка

Откройте popup, выберите исходный язык и цель, затем при необходимости перейдите в **Настройки** и нажмите **Подготовить**. Chrome бесплатно скачает нужный языковой пакет. В автоматическом режиме расширение заранее готовит пять возможных источников к выбранной цели, поэтому первая загрузка может быть заметно дольше. После загрузки перевод выполняется на устройстве.

Для всей страницы выберите отдельную цель **На русский** или **На английский**. Chrome создаёт локальный переводчик только после пользовательского клика. Поэтому на странице появляется подтверждение с выбранным языком и кнопкой **Начать**. После клика работа продолжится, даже если popup закрыть. Текст уже на выбранном языке остаётся оригинальным.

Для текста внутри картинки выберите исходный язык, нажмите **Выбрать область** в popup или `Alt+Shift+P`, затем обведите нужный фрагмент. Шесть моделей OCR уже входят в `dist`; отдельная загрузка для распознавания не нужна. Авто-OCR рассчитан на EN+RU, а UK/DE/FR/ES выбираются явно. Распознанный текст можно исправить перед повторным переводом.

Чтобы учить сохранённые слова, откройте вкладку **Карточки**. Сначала вспомните ответ, затем нажмите **Показать перевод** и оцените себя. Новые пары доступны сразу. «Повторить» возвращает карточку через 10 минут, «Сложно» — завтра, а «Знаю» постепенно увеличивает интервал. Прогресс сохраняется локально вместе со словарём.

Для PDF нажмите **Открыть PDF** на вкладке перевода. Документ откроется в просторной вкладке расширения: выберите файл или перетащите его, дождитесь чтения страниц, задайте язык и нажмите **Перевести**. Страницы без текстового слоя автоматически проходят локальный OCR. Кнопка **Скачать TXT** сохраняет текст перевода; исходная вёрстка PDF в TXT не переносится.

При неуверенном распознавании расширение дополнительно обрабатывает светлые надписи на цветном фоне. Если результат остаётся слабым, сначала предлагает проверить текст и нажать **Перевести этот текст**. Выделяйте надпись с небольшим отступом: лишние детали картинки могут мешать OCR.

## Интерфейс

- по умолчанию включён крупный масштаб 115%; доступны 100% и 130%;
- тёмная ягодно-розовая палитра, конфетно-розовые кнопки и значок-наклейка;
- аккуратные анимации и скруглённые карточки;
- полностью русский интерфейс;
- карточка измеряет свою высоту и открывается вверх у нижнего края окна.

## Ограничения Chrome

- Translator API и Language Detector API работают только в поддерживаемом настольном Chrome.
- На страницах `chrome://`, в Chrome Web Store и во встроенном просмотрщике PDF content script запрещён. Для PDF используйте кнопку **Открыть PDF** в popup и выберите локальный файл.
- Перевод страницы обрабатывает основной DOM-текст на момент запуска. Текст на видимой картинке или canvas можно перевести через выбор области; поля форм, код и закрытый Shadow DOM не обрабатываются. Отдельный PDF-раздел ограничен 20 МБ и 50 страницами; экспортирует текст, а не исходный макет.
- Разрешение на сайты нужно для снимка видимой вкладки после явного выделения области. Расширение не делает фоновые снимки.
- Если сайт изменил текстовый узел после перевода, восстановление не перезаписывает это новое содержимое.

## Разработка

Для локальной разработки и CI используется Node.js 24 LTS (проверено на 24.14.1). Версия закреплена в `.node-version` и `package.json`.

```powershell
npm ci
npm test
npm run typecheck
npm run build
npm run smoke
npx playwright install chromium
npm run smoke:browser
npm run smoke:ocr
```

Сборка создаёт папку `dist`, которую можно загрузить в Chrome. Иконки генерируются локально из `public/icons/poop.svg`.

Браузерный smoke запускает видимый Chromium с временным профилем; на Linux нужен графический сеанс или Xvfb. Переводчик в popup подменяется тестовой заглушкой, но OCR выполняется настоящим локальным Tesseract. `npm run smoke:ocr` отдельно проверяет снимок, обрезку и распознавание `HELLO OCR`, `ПРИВЕТ` и `GUTEN TAG`. Команда `npm run smoke:real` проверяет настоящий Chrome Translator API и завершается ошибкой, если языковой пакет не загрузился. CI выполняет тесты, типы, сборку и файловый smoke. Подробнее: [проверки и ручная приёмка](docs/testing.md).

## Детали поведения

- Ручной ввод ограничен 10 000 символами; сочетание Ctrl+Enter / Cmd+Enter запускает перевод.
- История содержит до 500 последних записей. Повтор одного запроса не дублируется; новый перевод того же текста может стать новой записью.
- Словарный поиск работает по точному нормализованному совпадению: до 80 символов и пяти слов. Показывается до восьми дополнительных значений без основного перевода. Это не полный перечень значений и не подбор по контексту; словоформы могут не находиться.
- Автоматический перевод определяет EN/RU/UK/DE/FR/ES. Для очень коротких латинских слов без достаточных признаков используется английский; исходный язык можно выбрать вручную.
- Для перевода страницы источник определяется по каждому фрагменту. Фрагменты уже на выбранной цели не меняются; при смешанных языках внутри одного текстового узла возможны неточные результаты.
- Content script работает только в верхнем документе: текст внутри iframe не обрабатывается. На HTTP-странице кнопка может появиться, но доступность встроенного API зависит от контекста браузера; при ошибке можно перенести текст в popup.
- Создание модели ограничено ожиданием 180 секунд. Это ограничение ожидания расширения, а не гарантия отмены загрузки Chrome.
- OCR поддерживает локальные модели `eng`, `rus`, `ukr`, `deu`, `fra`, `spa`. Авто-режим объединяет EN+RU; для других языков выберите источник явно. Качество зависит от размера, контраста, шрифта и чёткости изображения.
- Локальные данные не синхронизируются. Экспорт создаёт JSON на устройстве; импорт объединяет уникальные записи и применяет настройки из файла. Удаление расширения удаляет его хранилище, поэтому заранее сохраните резервную копию. Сброс данных расширения не удаляет языковые компоненты Chrome.
- Схема хранения v3 автоматически читает v1/v2 без потери истории, словаря и карточек. Экспорт создаёт копию v3; импорт принимает v1, v2 и v3, сохраняя более позднюю оценку совпадающей пары.
