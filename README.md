# poop translator

Бесплатный персональный переводчик для настольного Google Chrome. Поддерживает английский → русский, русский → английский и автоматический выбор направления. Перевод выполняет встроенный в Chrome Translator API: API-ключ, аккаунт и платная подписка не нужны.

## Установка

1. Убедитесь, что установлен Google Chrome версии 138 или новее.
2. Откройте `chrome://extensions`.
3. Включите «Режим разработчика» справа вверху.
4. Нажмите «Загрузить распакованное расширение».
5. Выберите папку `dist` из этого проекта.
6. Закрепите **poop translator** на панели Chrome.

После первой установки обновите уже открытые вкладки: content script начинает работать после перезагрузки страницы.

## Первая подготовка переводчика

Откройте popup расширения, выберите направление, перейдите в «Настройки» и нажмите «Подготовить». Chrome бесплатно скачает нужный языковой пакет; в автоматическом режиме подготавливаются обе пары EN ↔ RU. Прогресс появится рядом с кнопкой. Для первого скачивания нужен интернет; дальше перевод выполняется на устройстве.

Chrome разрешает создание локального переводчика только непосредственно после пользовательского клика. Поэтому перевод всей страницы, запущенный из popup, показывает внизу страницы небольшое подтверждение «Начать». После этого перевод продолжится в самой вкладке, даже если popup закрыть.

Если Chrome не завершит подготовку за три минуты, расширение остановит ожидание и предложит повторить. Уже начатую загрузку языкового компонента Chrome может завершить в фоне.

## Возможности

- выделите текст на обычной веб-странице и нажмите появившуюся кнопку;
- используйте отдельные команды ПКМ для перевода на русский или на английский;
- вводите текст вручную во вкладке «Перевод»;
- смотрите несколько значений отдельных слов и коротких фраз из встроенного словаря FreeDict;
- запускайте перевод основного текста страницы и возвращайте оригинал;
- ищите и удаляйте записи истории;
- добавляйте результат в словарь, редактируйте слова и заметки;
- выбирайте EN → RU, RU → EN или автоматический режим EN ↔ RU;
- выключайте историю и кнопку около выделения;
- очищайте историю, словарь или все локальные данные отдельно.

История, словарь и настройки находятся только в `chrome.storage.local`. Переводы страниц не сохраняются. Расширение не использует внешние переводческие серверы. Дополнительные значения загружаются из файлов внутри самого расширения и работают офлайн.

Изменения данных из popup и разных вкладок проходят через одну очередь service worker, поэтому одновременное добавление переводов не затирает соседние записи.

## Ограничения

- Translator API и Language Detector API доступны только в поддерживаемом настольном Chrome.
- На страницах `chrome://`, в Chrome Web Store и некоторых встроенных просмотрщиках внедрение content script запрещено. Ручной перевод в popup остаётся доступен.
- Перевод страницы обрабатывает снимок основного текста на момент запуска. Динамически появившиеся блоки можно перевести повторным запуском.
- Не переводятся изображения, canvas, PDF, элементы форм, код и закрытый Shadow DOM.
- При восстановлении расширение не затирает текстовый узел, если сайт изменил его после перевода.
- Короткие английские и русские слова в автоматическом режиме определяются по алфавиту; смешанный текст проверяет Language Detector API.

## Разработка

Требуется Node.js 20 или новее.

```powershell
npm install
npm test
npm run typecheck
npm run build
npm run smoke
```

Сборка создаёт/обновляет папку `dist`. Иконки генерируются локально из `public/icons/poop.svg`.

Локальные словарные данные получены из FreeDict. Авторство, версия и условия распространения указаны в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Ручная проверка

1. Подготовьте движок и переведите `Hello, how are you?` в popup.
2. Выделите английскую фразу у правого края окна и проверьте положение кнопки и карточки.
3. Повторите через контекстное меню.
4. Добавьте результат в словарь, измените заметку и удалите запись.
5. Выключите историю, выполните перевод и убедитесь, что запись не появилась.
6. Переведите страницу, закройте popup во время работы, затем верните оригинал.
7. Перезапустите Chrome и убедитесь, что история, словарь и настройки сохранились.
