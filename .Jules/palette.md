## 2023-10-30 - Tooltips for icon-only buttons and ARIA live regions for translation outputs
**Learning:** Icon-only buttons often have `aria-label` for screen reader accessibility, but this leaves sighted mouse users without context if the icon is ambiguous. Adding a `title` attribute resolves this by providing a native browser tooltip on hover. Additionally, dynamic content such as translation results appearing after a form submission should use `aria-live` regions (like `aria-live="polite"`) so that screen readers announce the text without requiring the user to manually move focus to the output area.
**Action:** Always pair `aria-label` with `title` for icon-only buttons unless an explicit tooltip component is used, and ensure dynamic critical outputs have `aria-live`.
