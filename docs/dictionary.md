# Встроенные варианты перевода

Сверено 2026-09-13. Личный словарь в storage и встроенные FreeDict-файлы — разные наборы данных.

`scripts/generate-dictionary.mjs` принимает путь к TEI и направление `eng-rus` или `rus-eng`. Он пишет JSON в `public/dictionary/<направление>/`: 26 английских и 33 русских буквенных файла. Встроенные файлы копируются в `dist` сборкой.

```powershell
node scripts/generate-dictionary.mjs .tmp-dictionary/eng-rus.tei eng-rus
node scripts/generate-dictionary.mjs .tmp-dictionary/rus-eng.tei rus-eng
npm test -- tests/dictionary.test.ts
npm run build
npm run smoke
```

TEI-файлы нужно предварительно получить из источников в [notices](../THIRD_PARTY_NOTICES.md); генератор сам их не скачивает. Эти URL обновляемые, поэтому скачивание сегодня не гарантирует точное воспроизведение включённой версии 2025.11.23. Сохранение контрольных сумм и неизменяемого источника — открытая задача.

Генератор удаляет ударение U+0301 и служебную разметку, нормализует пробелы и регистр ключа, исключает пустые и повторные переводы и сохраняет не более 16 вариантов на ключ. Берётся первая найденная часть речи записи; это не полноценная модель отдельных значений TEI. При обновлении проверьте разметку, части речи, количество ключей и варианты вручную.

Поиск использует точный ключ после нормализации, ограничивает запрос 80 символами и пятью словами. Морфологического поиска нет. UI показывает до восьми вариантов, исключая основной перевод и повторы. Ошибка загрузки фрагмента возвращает пустой список.

При смене источника или версии обновляйте `THIRD_PARTY_NOTICES.md` и `public/THIRD_PARTY_NOTICES.txt`, затем пересобирайте `dist`. Учитывайте ограничения преобразования в описании данных; лицензия кода MIT не заменяет CC BY-SA 3.0 словарей.
