# Local PDF Implementation Plan

**Goal:** Переводить локальный PDF (текстовый слой и скан) в отдельной розовой вкладке, без сервера и новых разрешений.

**Spec:** `docs/superpowers/specs/2026-09-16-local-pdf-design.md`.

## Task 1 — PDF core

- [x] Установить зафиксированную `pdfjs-dist`, добавить локальный worker, license notices и сборку.
- [x] TDD: текст страниц в правильном порядке, проверка 20 МБ/50 страниц, пустая страница использует OCR.

## Task 2 — вкладка PDF

- [x] Русский розовый интерфейс для файла, списка страниц, цели, прогресса/отмены/ошибок/экспорта TXT.
- [x] Chrome Translator стартует из клика; состояние генерации предотвращает устаревшие ответы; файл не попадает в storage.
- [x] Popup открывает PDF вкладку; browser smoke покрывает локальный text PDF, OCR fallback и перевод через тестовую заглушку.

## Task 3 — выпуск

- [x] Version1.6.0, README, CHANGELOG, testing, архитектура, AGENTS.md, notices, smoke на worker/fixture.
- [x] `npm test`, `npm run typecheck`, `npm run build`, `npm run smoke`, `npm run smoke:browser`, `npm run smoke:ocr`, `git diff --check`.
- [ ] Обновить установленную папку, публичный коммит и отдельный PR поверх `codex/page-target`; дождаться CI.
