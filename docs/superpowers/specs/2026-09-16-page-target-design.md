# Язык перевода страницы — дизайн версии 1.5.0

Смешанная EN/RU-страница сейчас может остаться двуязычной: общий режим «Авто» для каждого фрагмента меняет направление, поэтому русский текст переводится на английский даже когда пользователь хотел страницу целиком на русском. Выбор исходного языка ручного перевода также не выражает цель перевода страницы.

## Решение

В блоке «Вся страница» popup появляется отдельный выбор «На русский» или «На английский» (по умолчанию русский). Выбор сохраняется в существующих локальных настройках v2 и автоматически нормализуется для старых сохранений и копий. В подтверждении на странице явно написан выбранный язык.

При запуске Chrome Translator создаёт нужную пару EN→RU или RU→EN и Language Detector до первого `await` в обработчике клика. Для каждого текстового фрагмента источник определяется среди EN/RU. Фрагменты уже на целевом языке остаются оригинальными; остальные переводятся в выбранном направлении. Отмена, восстановление, защита от устаревших операций и отсутствие переводов страниц в истории сохраняются.

## Варианты и границы

Использовать общий `sourceMode` для страницы проще, но он не даёт устойчивого целевого языка в режиме «Авто». Перевод в service worker нарушил бы контракт пользовательской активации Chrome AI. Поэтому страница получает собственный target; ручной перевод и выделение продолжают пользоваться своим режимом.

На этом этапе источник определяется только между английским и русским. Chrome официально перечисляет дополнительные языки Translator API, но поддержку конкретной пары следует проверять через `availability()`; расширение не обещает их до отдельной реализации и проверок. OCR-языки и PDF рассматриваются следующим этапом. Сборка не добавляет разрешений и внешние сервисы.

## Проверка

Детектор запускается из клика, но его загрузка не блокирует готовый переводчик страницы. Для однозначного латинского или кириллического фрагмента источник определяется по алфавиту.

Тесты охватывают отсутствие обратного перевода для фрагментов уже на цели, подготовку нужной пары синхронно из клика, нормализацию настройки из старых данных, валидацию runtime target и неизменность ручного EN↔RU. Browser smoke проверяет русский выбор, направление сообщения и текст подтверждения; работа настоящей модели проверяется отдельно по `docs/testing.md`.
