# Poop Translator Design

Сверено с кодом версии 1.5.0 на 2026-09-16. Это описание реализации; история аудита и оставшиеся предложения перечислены в [аудите](../../audit-2026-09-13.md).

## Цель

Создать бесплатное персональное расширение Chrome «poop translator» для перевода между английским и русским: вручную, из выделения, контекстного меню и для основного содержимого страницы. История, словарь и настройки хранятся только в `chrome.storage.local`.

## Техническое решение

Расширение использует Manifest V3, TypeScript и Vite без UI-фреймворка. Встроенный Chrome Translator API переводит текст без ключа и после загрузки языкового пакета работает локально. Tesseract.js 7 с локальными моделями `eng`/`rus` распознаёт выбранную область. Перевод запускается в popup или content script; service worker создаёт меню, маршрутизирует команды и снимает видимую вкладку, а OCR выполняется в offscreen document.

Для исходного языка доступны `en`, `ru` и `auto`. Автодетект различает чисто латинский и кириллический текст локально, а для смешанного текста использует Language Detector API. Автоматическая подготовка запускает обе пары EN ↔ RU внутри пользовательского клика и показывает прогресс.

Несколько значений отдельных слов и коротких фраз берутся из встроенных словарей FreeDict EN→RU и RU→EN. Данные разбиты по направлению и первой букве, поэтому загружается только нужный фрагмент. Запросы к внешним словарным сервисам не выполняются.

## Компоненты

- `background.ts`: установка контекстного меню, захват видимой вкладки, доставка команд и единая очередь изменений `chrome.storage.local`.
- `content.ts`: кнопка у выделения, рамка OCR, Shadow DOM карточка результата, перевод страницы, восстановление оригинала.
- `ocr/`: offscreen-документ, crop снимка и переиспользуемый локальный Tesseract worker.
- `popup/`: ручной перевод, история, словарь, карточки повторения, настройки, запуск перевода страницы и области.
- `core/translator.ts`: адаптер Chrome Translator/LanguageDetector с проверкой доступности, прогрессом и понятными ошибками.
- `core/dictionary.ts`: локальный поиск нескольких значений и фильтрация повторов.
- `core/storage.ts`: версия схемы, миграция v1, история, словарь, прогресс карточек, настройки и последовательная запись.
- `core/review.ts`: чистые функции сроков и выбор доступных словарных карточек.
- `core/page-translation.ts`: выбор текстовых узлов, пакетирование и безопасное восстановление.
- `shared/`: типы, протокол сообщений и идентификаторы запросов.

## Потоки данных

Ручной перевод выполняется в popup, после успеха popup добавляет запись в историю. Кнопка выделения выполняет перевод в content script. Для OCR content script удаляет рамку, service worker снимает вкладку, а offscreen document обрезает снимок и распознаёт текст; снимок не сохраняется. Popup и content script отправляют изменения данных в service worker, поэтому записи разных вкладок проходят через одну очередь. Перевод страницы выполняется в content script пакетами и не сохраняется в историю.

## Перевод страницы

Popup сохраняет отдельную цель страницы «На русский» / «На английский». После подтверждения content script готовит нужную пару. Источник определяется для каждого фрагмента между EN/RU; фрагменты уже на цели не переписываются. Переводы страниц не записываются в историю.

Content script выбирает `main`, `article`, `[role=main]` или `body`, собирает видимые текстовые узлы и пропускает `script`, `style`, `code`, `pre`, формы, `contenteditable` и элементы расширения. Исходное значение и последнее значение расширения хранятся в `Map<Text, Snapshot>`. При восстановлении узел меняется только если его текущее значение совпадает с последним переводом расширения. Операция поддерживает отмену и прогресс.

## Данные

Цель страницы хранится в `settings.pageTargetLanguage`; старые данные нормализуются к `ru`, импорт v1/v2 сохраняет эту настройку.

Схема `v2` содержит `settings`, `history`, `dictionary` и разреженный `review` с ID словарной пары, сроком, датой последней оценки и серией успешных ответов. Старую схему v1 нормализация читает без потери истории и словаря. Настройки включают направление, историю, кнопку выделения и масштаб текста 100/115/130% с крупным значением 115% по умолчанию. История ограничивается 500 последними записями. Дубликаты истории по `requestId`, а словаря по нормализованной паре `original + translation` не создаются. При выключенной истории новые переводы не записываются. JSON-копия версии 2 экспортирует прогресс; импорт принимает версии 1 и 2, объединяет уникальные записи через очередь service worker и сохраняет более позднюю оценку совпадающей пары.

## Интерфейс

Popup шириной 404 px имеет пять вкладок: «Перевод», «История», «Словарь», «Карточки», «Настройки». Визуальный образ — карманная игрушка-переводчик: тёмные сливово-графитовые поверхности, насыщенный розовый и сиреневый акценты, мягкие скругления, масштабируемый текст, крупные состояния фокуса и маленький poop-персонаж. Варианты перевода выводятся кнопками и добавляются в личный словарь одним нажатием. Карточки показывают сначала крупное слово, затем ответ и оценки повторения. Карточка выделения измеряется после каждого изменения содержимого, открывается вверх при нехватке места снизу и всегда ограничивается viewport. Анимации отключаются через `prefers-reduced-motion`.

## Ошибки и ограничения

На системных страницах Chrome и во встроенном PDF viewer content script недоступен; popup сообщает об этом. Первая загрузка модели перевода может занять время. Динамически добавленный текст страницы переводится при повторном запуске. Видимый текст на canvas и изображениях доступен через OCR-рамку; невидимая часть, PDF и закрытый Shadow DOM не обрабатываются. Качество OCR зависит от размера и контраста.

## Проверка

Vitest покрывает нормализацию данных, историю, локальные словарные варианты, оба направления через заглушки API, OCR-геометрию, разбиение текста и безопасное восстановление DOM. `npm run typecheck` проверяет типы отдельно от сборки Vite. `npm run smoke` проверяет manifest, OCR-ресурсы, обязательные файлы и два словарных фрагмента.

`npm run smoke:browser` загружает `dist` в Chromium с временным профилем. В popup Translator и LanguageDetector заменены заглушками; Tesseract остаётся настоящим. Проверяются UI, storage RPC, карточки, backup v1, масштаб, выделение, приглашение перевода страницы и локальный OCR. `npm run smoke:ocr` отдельно проверяет capture, crop и распознавание. `npm run smoke:real` проверяет настоящий Translator API, если Chromium смог скачать языковой пакет. Ручная проверка описана в [testing.md](../../testing.md).
