# Локальный перевод PDF — дизайн версии 1.6.0

Пользователь открывает раздел «PDF» из popup в отдельной вкладке расширения, выбирает файл с устройства или перетаскивает его. Файл остаётся в памяти вкладки: расширение не записывает его и не отправляет наружу. PDF.js, собранный вместе с расширением, извлекает текст каждого листа. Если на листе нет текстового слоя, локальный Tesseract распознаёт его отрисованное изображение. Результат показывается парами «Оригинал / Перевод» по страницам. Пользователь может выбрать цель RU или EN, запустить перевод, отменить работу и сохранить переведённый текст как TXT.

Формат PDF сохраняется только во входном файле: TXT экспортирует текст, а не макет исходного документа. На первом этапе поддерживается автоматическое определение источника между EN/RU, с сохранением фрагментов уже на целевом языке. OCR использует eng/rus; будущая поддержка дополнительных языков расширит этот выбор. Сканированные страницы распознаются последовательным OCR без долгоживущего снимка. Лимиты 20 МБ, 50 страниц, 16 млн пикселей на встроенное изображение, 100 тыс. символов на страницу и 1 млн на документ ограничивают память и время. Повреждённый, защищённый или превышающий бюджет PDF даёт понятную ошибку без потери ранее загруженного результата; новый набор страниц показывается только после полного успешного извлечения.

Кнопка **Начать перевод** синхронно вызывает Chrome Translator `create()` из пользовательского клика до первого `await`; загрузка PDF выполняется отдельным действием. Вкладка доступна с клавиатуры, объявляет прогресс и ошибки, учитывает `prefers-reduced-motion` и крупный текст. Новых Chrome-разрешений нет. PDF и его перевод не записываются в историю или словарь автоматически; в словарь можно вручную добавить фразу через существующий popup.

Проверки: модульные тесты извлечения порядка строк и ограничения объёма; локальный текстовый и сканированный PDF fixture; браузерный smoke открытия из popup, извлечения, перевода через заглушку и скачивания TXT; smoke:ocr остаётся настоящим OCR. Доступность реальной Chrome AI модели отдельно оценивается `smoke:real`/ручной приёмкой.
