# Проверки версии 1.3.0

Сверено 2026-09-15.

| Команда | Что проверяет | Чего не доказывает |
| --- | --- | --- |
| `npm test` | 56 тестов в 11 файлах: storage/backup, сообщения, словарь, геометрия OCR, UI shell, позиционирование карточки, адаптер API и DOM-сессия | Работа настоящей языковой модели и качество OCR на произвольных картинках |
| `npm run typecheck` | TypeScript в src, tests и Vite config | Выполнение кода браузером |
| `npm run build` | Генерация иконок, popup/background/offscreen, IIFE content script и локальные OCR-ресурсы | Проверка типов и реальный перевод |
| `npm run smoke` | 18 обязательных файлов, MV3, OCR-permissions/CSP, отсутствие ESM import в content bundle, локальные OCR-модели, лицензии и два примера словаря | Полная валидация всех словарей и браузерные сценарии |
| `npm run smoke:browser` | Chromium, UI, runtime RPC, импорт, масштаб, направления через заглушки, выделение, фокус/отмена рамки, приглашение страницы и настоящий локальный OCR области | Настоящий Chrome Translator, качество OCR на сложных изображениях и native ПКМ |
| `npm run smoke:ocr` | Реальный снимок вкладки, CSS→bitmap crop, offscreen/Tesseract и редактируемое распознавание `HELLO OCR` и `ПРИВЕТ` | Перевод распознанного текста и качество OCR на произвольных шрифтах |
| `npm run smoke:real` | Настоящий Translator API в Playwright Chromium, обе пары и выделение при доступном пакете | Native ПКМ; гарантированную загрузку компонента в каждой среде |

CI выполняет `npm test`, `npm run typecheck`, `npm run build` и `npm run smoke` после `npm ci`. Браузерные сценарии запускаются отдельно: установите Chromium через `npx playwright install chromium`. Они открывают видимое окно, используют временный профиль и удаляют его после завершения. На Linux нужен display, например `xvfb-run -a npm run smoke:browser` после установки Xvfb и зависимостей браузера.

Для сохранения скриншота на Windows:

```powershell
$env:POOP_TRANSLATOR_SCREENSHOT_PATH = 'output/playwright/poop-translator-popup.png'
npm run smoke:browser
Remove-Item Env:POOP_TRANSLATOR_SCREENSHOT_PATH
```

`smoke:real` не устанавливает `SmokeTranslator`. Стабильные Google Chrome и Edge больше не принимают флаги боковой загрузки расширений, поэтому автоматический сценарий использует поставляемый Playwright Chromium: [документация Playwright](https://playwright.dev/docs/chrome-extensions). На проверенной машине Chromium 153 увидел EN→RU и RU→EN как `downloadable`, но пакет не завершил загрузку за 190 секунд; сценарий корректно завершился ошибкой. Для быстрой диагностики можно задать `POOP_TRANSLATOR_REAL_TIMEOUT_MS`. Окончательную проверку установленного Google Chrome выполняйте вручную.

## Ручная приёмка в установленном Google Chrome

1. Загрузить `dist` через `chrome://extensions`, записать версию Chrome и ОС.
2. Подготовить EN → RU; перевести `The cat is sleeping on the chair.` и проверить смысл. Затем RU → EN: `Кошка спит на стуле.`. Не требовать единственной дословной формулировки.
3. Повторить в авто-режиме, проверить чисто русский, английский и смешанный текст.
4. На обычной HTTPS-странице проверить выделение, карточку у края окна и оба пункта настоящего контекстного меню. При требовании активации нажать «Повторить».
5. Нажать «Выбрать область» и обвести крупный EN-текст на картинке; проверить редактирование и повторный перевод. Повторить с RU-текстом и через `Alt+Shift+P`.
6. Перевести `bank`, добавить отдельный вариант в словарь, изменить заметку, проверить отсутствие дубля при повторном добавлении пары.
7. Выключить историю и проверить, что новые записи не добавляются; включить обратно.
8. Запустить перевод страницы, нажать «Начать», закрыть popup и дождаться изменения текста. Вернуть оригинал. Проверить отмену и повторный запуск.
9. Проверить, что формы и код не затронуты; изменение текстового узла самим сайтом не должно затираться при восстановлении.
10. Перезапустить Chrome и проверить сохранение словаря, истории и настроек.
11. После подготовки повторить перевод и OCR без сети. Записать результат отдельно от автоматического smoke.

Не сохранять личный текст и профиль браузера в тестовые артефакты репозитория.
