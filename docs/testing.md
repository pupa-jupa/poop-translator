# Проверки версии 1.2.0

Сверено 2026-09-14.

| Команда | Что проверяет | Чего не доказывает |
| --- | --- | --- |
| `npm test` | 50 тестов в 9 файлах: storage/backup, сообщения, словарь, UI shell, позиционирование карточки, адаптер API и DOM-сессия | Работа настоящей языковой модели |
| `npm run typecheck` | TypeScript в src, tests и Vite config | Выполнение кода браузером |
| `npm run build` | Генерация иконок, popup/background и IIFE content script | Проверка типов и реальный перевод |
| `npm run smoke` | 9 обязательных файлов, MV3, отсутствие ESM import в content bundle, два примера словаря | Полная валидация всех словарей и браузерные сценарии |
| `npm run smoke:browser` | Chromium, UI, runtime RPC, импорт, масштаб, скрытие завершённого статуса, направления через заглушки, кнопка выделения, приглашение страницы | Загрузка модели, реальный перевод выделения и страницы, native ПКМ |
| `npm run smoke:real` | Настоящий Translator API в Playwright Chromium, обе пары и выделение при доступном пакете | Native ПКМ; гарантированную загрузку компонента в каждой среде |

CI выполняет первые четыре команды после `npm ci`. Браузерные сценарии запускаются отдельно: установите Chromium через `npx playwright install chromium`. Они открывают видимое окно, используют временный профиль и удаляют его после завершения. На Linux нужен display, например `xvfb-run -a npm run smoke:browser` после установки Xvfb и зависимостей браузера.

Для сохранения скриншота на Windows:

```powershell
$env:POOP_TRANSLATOR_SCREENSHOT_PATH = 'output/playwright/poop-translator-popup.png'
npm run smoke:browser
Remove-Item Env:POOP_TRANSLATOR_SCREENSHOT_PATH
```

`smoke:real` не устанавливает `SmokeTranslator`. Стабильные Google Chrome и Edge больше не принимают флаги боковой загрузки расширений, поэтому автоматический сценарий использует поставляемый Playwright Chromium: [документация Playwright](https://playwright.dev/docs/chrome-extensions). На проверенной машине Chromium 153 увидел EN→RU и RU→EN как `downloadable`, но пакет не завершил загрузку за 190 секунд; сценарий корректно завершился ошибкой. Для быстрой диагностики можно задать `POOP_TRANSLATOR_REAL_TIMEOUT_MS`. Окончательную проверку установленного Google Chrome выполняйте вручную.

## Ручная приёмка в установленном Google Chrome

1. Загрузить `dist` через `chrome://extensions`, записать версию Chrome и ОС.
2. Подготовить EN → RU; перевести `The cat is sleeping on the chair.` и проверить смысл. Затем RU → EN: `Кошка спит на стуле.`. Не требовать единственной дословной формулировки.
3. Повторить в авто-режиме, проверить чисто русский, английский и смешанный текст.
4. На обычной HTTPS-странице проверить выделение, карточку у края окна и оба пункта настоящего контекстного меню. При требовании активации нажать «Повторить».
5. Перевести `bank`, добавить отдельный вариант в словарь, изменить заметку, проверить отсутствие дубля при повторном добавлении пары.
6. Выключить историю и проверить, что новые записи не добавляются; включить обратно.
7. Запустить перевод страницы, нажать «Начать», закрыть popup и дождаться изменения текста. Вернуть оригинал. Проверить отмену и повторный запуск.
8. Проверить, что формы и код не затронуты; изменение текстового узла самим сайтом не должно затираться при восстановлении.
9. Перезапустить Chrome и проверить сохранение словаря, истории и настроек.
10. После подготовки повторить перевод без сети. Записать результат отдельно от автоматического smoke.

Не сохранять личный текст и профиль браузера в тестовые артефакты репозитория.
