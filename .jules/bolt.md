## 2024-10-18 - Memoize ancestor checks in DOM TreeWalker
**Learning:** During page translation, a `TreeWalker` is used to visit every text node and check if it should be skipped by walking up its ancestor chain via `isSkippedElement`. For deep DOM structures, this involves highly redundant traversal and repeated `getComputedStyle` calls for text nodes sharing the same parent or ancestors, yielding an effective O(N*depth) complexity which becomes a performance bottleneck for large pages.
**Action:** Always memoize ancestor-dependent checks (like `getComputedStyle` or attribute existence) using a `WeakMap<Element, boolean>` when repetitively checking elements inside a `TreeWalker` loop. Tracking visited paths in an array during traversal and populating the `WeakMap` with the computed result brings the cost down to amortized O(1) per node.
