## 2024-05-19 - DocumentFragment batch rendering and Event Debouncing
**Learning:** For rendering long lists in standard DOM (like the History and Dictionary list arrays reaching up to 500 length) iterative `.append` calls without a DocumentFragment trigger successive layout recalculations causing rendering blocking and lag. Adding continuous Event Listeners such as `input` onto lists without wrapping them in a Debouncer results in extreme continuous unneeded triggering.
**Action:** Used `document.createDocumentFragment()` to accumulate elements in a single fragment during large loops and call `.replaceChildren(fragment)` rather than individually appending. Created a custom generic `.debounce` function utilizing `.setTimeout` and wrapped the `input` event triggers (keystrokes) with 150ms delay intervals to limit the update executions during user rapid input.
