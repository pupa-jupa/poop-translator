## 2024-05-18 - TreeWalker Traversal Optimization
**Learning:** In `src/core/page-translation.ts`, `collectTextNodes` was previously using a TreeWalker with `SHOW_TEXT`, iterating over all text nodes. For each text node, `isSkippedElement` traversed *up* the DOM tree from the text node's parent to the root, checking classes, tag names, and even invoking `getComputedStyle` on *every* text node. This means if a `<div class="skip">` has 100 text nodes, the div is checked 100 times. `getComputedStyle` is extremely expensive because it forces a synchronous layout calculation (layout thrashing) in the browser, making this $O(N)$ operation per element extremely slow when applied to every single text descendant.
**Action:** Changed the TreeWalker to use `NodeFilter.SHOW_ELEMENT | NodeFilter.SHOW_TEXT`. When encountering an element, it checks if it should be skipped. If so, it returns `NodeFilter.FILTER_REJECT` to skip the entire subtree in one go, avoiding redundant checks and `getComputedStyle` calls for all its descendants. Only do the skip checks *once* per element.
