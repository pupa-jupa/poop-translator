## 2024-11-01 - TreeWalker DOM Traversal Performance Edge Case
**Learning:** During heavy DOM manipulation (like TreeWalker iteration of thousands of text nodes), checking ancestor elements individually causes redundant work, resulting in O(depth) complexity per text node. A naive `WeakMap` implementation might only cache the top-level element result, but children won't correctly inherit the memoized states of their ancestors if the tree path isn't explicitly updated iteratively.
**Action:** When implementing iterative memoization for DOM ancestor traversal checks, collect all traversed elements in an array path and apply the final boolean result to all elements in the path before returning. Scope the `WeakMap` instance strictly to the execution lifecycle of the specific traversal (e.g., initialized inside the TreeWalker iteration function) to guarantee safety against stale caches if the DOM mutates later.
