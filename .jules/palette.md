## 2024-05-24 - Accessibility Enhancements for Dynamic Text & Icon-Only Buttons
**Learning:** In highly dynamic, interactive vanilla DOM extensions like this one, it is easy to forget `title` attributes on icon-only buttons (like `pt-selection-button` and `pt-icon-button` in the content layer and modal closures in the popup), which are critical for sighted users to understand their purpose when hovering over them. Furthermore, dynamic text areas (e.g. the translation result card `data-result` and engine status `<p data-engine-detail>`) require `aria-live="polite"` so screen readers can automatically announce changes.
**Action:** When adding or updating icon-only buttons, always ensure a `title` attribute mirrors the `aria-label`. When creating or updating containers that act as target areas for dynamically fetched text or state information, include an `aria-live="polite"` attribute to ensure screen reader users are kept informed of asynchronous UI updates.
